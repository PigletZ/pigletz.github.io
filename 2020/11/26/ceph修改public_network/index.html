ceph修改public_network

通过 monmap 调整 Ceph public_network，记录 Monitor 网络变更流程。

P JH Zeng · #mon

发表于 2020-11-26 · 本文保留当年的技术记录，使用前请结合当前版本文档核对。

获取mon map

TEXT
ceph mon getmap -o monmap

删除旧的map配置，添加新的map

修改前，先保存一份用于备份恢复

TEXT
monmaptool --rm ｛nodename｝ --rm {nodename} --rm {nodename} monmap

添加新ip配置：
monmaptool --add {nodename} {ip}:6789 --add {nodename} {ip}:6789 --add {nodename} {ip}:6789 monmap

查看修改后的monmap：

注入前预处理

（1）修改ceph.conf 中的ip地址为新的ip地址，并将配置文件更新至所有节点，monmap拷贝至mon节点即可

TEXT
vi /etc/ceph/ceph.conf
mon_host = ip1,ip2,ip3
public_network = 10.100.64.0/18

----------------------------

更新ceph.conf至所有节点
scp /etc/ceph/ceph.conf root@{nodename}:/etc/ceph/

拷贝monmap至所有mon节点，以备后续的注入
scp monmap root@{nodename}:/root

（2）将集群设置noout，防止重启osd，重平衡带来的负载，若有recover，尽量等recover修复好再进行操作，防止osd拉不起或者损坏带来的数据丢失。

TEXT
ceph osd set noout

（3）停止所有的mon服务

TEXT
去各自的mon节点执行停止服务
systemctl stop ceph-mon@{nodename}

注入新的monmap

TEXT
去到各自的mon节点，执行

ceph-mon -i {nodename} --inject-monmap /root/monmap

查看修改后的mon状态：
root@xjcc-1-80:~/piglet# ceph mon stat

重启所有服务

TEXT
重启每个节点对应角色的target服务，如osd节点：
systemctl restart ceph-osd.target
